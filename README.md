# День 02. Telegram-бот: Личный учет расходов

## 🧩 Задание 2. «Telegram-бот: Личный учет расходов»

### Общие сведения
- **Технологии**: Telegram Bot API (только текст/команды), ASP.NET Core, JSON (хранение), Работа с датами (DateTime)
- **Назначение**: Быстрый учет расходов через Telegram-бот с возможностью получения статистики

### Легенда
Пользователю нужно быстро записывать траты в чат с ботом и моментально получать ответы на вопросы: «Сколько я потратил сегодня?», «А за неделю?».

## 📋 Требования

### Хранение данных
- Все расходы хранятся в файле `expenses.json`
- Структура записи:
```json
{
  "id": "guid-string",
  "userId": 123456789,
  "amount": 500.50,
  "reason": "Обед в кафе",
  "createdAt": "2026-03-11T14:30:00Z"
}
```

### Обработка входящих сообщений
- Бот реагирует только на текстовые сообщения (`message.Type == Text`)
- Если сообщение — картинка, стикер или голосовое → игнорировать или отвечать: «Я понимаю только текст и команды»

### Формат добавления расхода
Пользователь пишет сообщение в формате: `<сумма> <причина>`

**Примеры:**
- `500 Обед`
- `1200.50 Такси до офиса`
- `100 Кофе`

**Логика парсинга:**
- Первое слово пытается распарсить как `decimal` (сумма)
- Если успешно – всё остальное сообщение считается причиной
- Если первое слово не число – ответить ошибкой: «Ошибка: Начните сообщение с суммы (числа). Пример: 500 Обед»
- При успешном добавлении: сохранить в JSON и ответить: «Записано: {сумма} руб. ({причина})»

### Команды отчетности
Бот должен поддерживать следующие команды (регистр не важен):

- `/today` — Расходы за сегодня (с 00:00 до текущего момента по времени сервера)
  - Ответ: «За сегодня потрачено: {сумма} руб. (записей: {count})»

- `/week` — Расходы за последние 7 дней (включая сегодня)
  - Ответ: «За последние 7 дней: {сумма} руб.»

- `/month` — Расходы за текущий календарный месяц (с 1-го числа по текущую дату)
  - Ответ: «За этот месяц: {сумма} руб.»

- `/last` — Список последних 10 трат (независимо от даты)
  - Ответ (списком):
    ```
    1. 500 руб. | Обед (11.03 14:30)
    2. 1200 руб. | Такси (11.03 12:15)
    3. 100 руб. | Кофе (10.03 18:00)
    ```

- `/start` или `/help` — Вывод инструкции со всеми командами и примером формата ввода

## 🚀 Реализация

### Основные компоненты:
1. **ASP.NET Core Web API** для обработки вебхуков Telegram
2. **ExpenseService** для работы с JSON файлом расходов
3. **BotController** для обработки входящих сообщений
4. **Expense model** для структуры данных

### Ключевые моменты:
- Использование `System.Text.Json` для сериализации/десериализации
- Работа с `DateTime` для фильтрации по периодам
- Парсинг текстовых сообщений для извлечения суммы и причины
- Генерация GUID для уникальных ID записей
