## 📋 Задания конкурса

### Задание 1 - Анализатор лог файлов ✅
**Статус:** Завершено  
**Описание:** Консольное приложение на C# для анализа лог файлов и генерации отчетов об ошибках и предупреждениях.

#### 📁 Переход к проекту:
**[ConsoleApp2 - Анализатор лог файлов](./ConsoleApp2/)**

#### 🎯 Краткое описание:
- Обработка лог файлов в формате `[TIMESTAMP] [LEVEL] Message`
- Фильтрация записей уровней ERROR и WARN
- Генерация JSON отчетов со статистикой
- Группировка сообщений по частоте встречаемости

#### 🛠 Технологии:
- C# 10 (.NET 10.0)
- System.Text.Json
- LINQ
- Регулярные выражения

## 🚀 Как использовать проекты

### Для запуска Задания 1:
1. Перейдите в папку проекта: `cd ConsoleApp2`
2. Запустите приложение: `dotnet run --project ConsoleApp2`
3. Или с указанием пути к лог файлу: `dotnet run --project ConsoleApp2 "path/to/app.log"`

### Требования:
- .NET 10.0 SDK
- Visual Studio 2022 или VS Code
