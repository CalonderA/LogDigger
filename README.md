# День 03. Хранилище ключ-значение с TTL

## 🧩 Задание 3. «Хранилище ключ-значение с TTL»

### Общие сведения
- **Технологии**: ASP.NET Core, JSON, Работа со временем (DateTime)
- **Назначение**: Легкий сервис для хранения временных данных: кодов подтверждения, токенов сброса пароля, сессионных ключей

### Легенда
Команде нужен легкий сервис для хранения временных данных: кодов подтверждения, токенов сброса пароля, сессионных ключей. Данные должны автоматически «протухать» через заданное время и удаляться из хранилища.

## 📋 Требования

### Модель данных
Каждая запись в хранилище имеет следующую структуру:
```json
{
  "key": "user_123_verification_code",
  "value": "558822",
  "expiresAt": "2026-03-11T10:05:00Z",
  "createdAt": "2026-03-11T10:00:00Z"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| key | string | Уникальный идентификатор (1-100 символов) |
| value | string | Значение (1-1000 символов) |
| expiresAt | DateTime | Время истечения (UTC) |
| createdAt | DateTime | Время создания (UTC) |

### API (`/api/cache`)

| Метод | Эндпоинт | Тело запроса | Ответ |
|-------|----------|--------------|-------|
| POST | `/set` | `{ "key", "value", "ttlSeconds" }` | 200/201 — `{ "key", "expiresAt" }` |
| GET | `/get/{key}` | — | 200 — данные, 404 — не найдено или истекло |
| DELETE | `/{key}` | — | 204 — удалено, 404 — не найдено |
| GET | `/stats` | — | 200 — `{ "total", "active", "expiringSoon", "expired" }` |

### Логика работы

**TTL**: `expiresAt = DateTime.UtcNow + TimeSpan.FromSeconds(ttlSeconds)`

**Ленивая очистка**: При любом запросе удалять записи, у которых `expiresAt < DateTime.UtcNow`

**Обновление**: Если ключ существует — перезаписать `value` и `expiresAt`

### Валидация

| Поле | Правило | Ошибка |
|------|---------|--------|
| key | 1-100 символов, латиница + цифры + подчеркивание | 400 Bad Request |
| value | 1-1000 символов, не пустой | 400 Bad Request |
| ttlSeconds | 1–86400 (до 24 часов) | 400 Bad Request |

## 🚀 Реализация

### Основные компоненты:
1. **ASP.NET Core Web API** для обработки HTTP-запросов
2. **CacheService** — потокобезопасное хранилище на `ConcurrentDictionary`
3. **CacheController** — обработка endpoint'ов с валидацией
4. **Модели** — структуры данных для запросов/ответов

### Ключевые моменты:
- Использование `ConcurrentDictionary<string, CacheEntry>` для потокобезопасности
- Ленивая очистка истекших записей при каждом запросе
- Регулярные выражения для валидации ключа (`^[a-zA-Z0-9_]+$`)
- Работа с `DateTime.UtcNow` для корректного времени истечения
