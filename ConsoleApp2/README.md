# Задание 1 - Анализатор лог файлов

## Проект: Вызов3.0 | КОД

### Описание проекта
Консольное приложение на C# для анализа лог файлов и генерации отчетов об ошибках и предупреждениях.

### Задание
Разработать консольное приложение, которое обрабатывает лог файлы и создает отчеты в формате JSON.

## Функциональность

### Входные данные
- Приложение принимает путь к файлу `app.log` в качестве аргумента командной строки
- Файл `app.log` находится в папке рядом с проектом (или по указанному пути)
- Формат каждой строки лога:
  ```
  [TIMESTAMP] [LEVEL] Message
  ```
  Пример: `[2026-03-11 10:00:01] [ERROR] Database connection failed.`
- Уровни: `INFO`, `WARN`, `ERROR`, `DEBUG`

### Логика обработки
- Прочитать файл лога по указанному пути
- Отфильтровать только строки с уровнем **ERROR** и **WARN**
- Сгруппировать записи по тексту сообщения (игнорируя временную метку)
- Посчитать количество вхождений для каждого уникального сообщения для каждого уровня отдельно

### Выходные данные
- Создать файл `report.json` **рядом с `app.log`** (в той же папке)
- Вывести содержимое `report.json` в консоль

### Структура `report.json`
```json
{
  "generatedAt": "2026-03-11T12:00:00",
  "totalErrors": 15,
  "totalWarns": 8,
  "topIssues": [
    { "message": "Database connection failed", "count": 10, "level": "ERROR" },
    { "message": "Disk space low", "count": 5, "level": "WARN" }
  ]
}
```

Где:
- `generatedAt` — текущая дата и время формирования отчёта в формате ISO 8601
- `totalErrors` — общее количество всех записей уровня ERROR
- `totalWarns` — общее количество всех записей уровня WARN
- `topIssues` — массив, содержащий **одно самое частое сообщение уровня ERROR** и **одно самое частое сообщение уровня WARN**

## Технологии
- **C# 10** (.NET 10.0)
- **System.Text.Json** для сериализации JSON
- **Регулярные выражения** для парсинга логов
- **LINQ** для фильтрации и группировки данных

## Запуск приложения

### 1. Без аргументов (использует app.log в текущей папке)
```bash
dotnet run --project ConsoleApp2
```

### 2. С указанием пути к файлу лога
```bash
dotnet run --project ConsoleApp2 "C:\path\to\your\app.log"
```

## Обработка ошибок
Приложение корректно обрабатывает следующие ситуации:
- Файл лога не найден
- Некорректный формат строк в логе
- Ошибки при создании отчета
- Ошибки при записи в файл

## Особенности реализации
- **Асинхронное чтение файла** для производительности
- **Регулярные выражения** для надежного парсинга формата лога
- **LINQ** для эффективной фильтрации и группировки
- **Строгая типизация** с использованием enum для уровней лога
- **Обработка исключений** с информативными сообщениями об ошибках
